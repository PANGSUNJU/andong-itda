# 사용자 테스트 — 홈의 목적지 기능

이 서비스는 설계상 아무것도 수집하지 않는다(→ ADR-024). 그래서 **"이 기능이 실제로
쓸모 있는가"를 데이터로 알 방법이 없다.** 사람에게 시켜 보는 것이 유일한 길이다.

## 규칙

- **설명하지 않는다.** 과제만 읽어 주고 손을 떼라. 설명하는 순간 그 화면은 설명이
  필요한 화면이라는 사실이 가려진다.
- **막히면 그냥 본다.** 힌트를 주지 않는다. 포기하면 포기한 것을 적는다.
- **소리 내어 읽게 한다.** 잘못 읽은 문장이 가장 값진 기록이다.
- 한 사람에 15분. 두 사람이면 충분하다.

## 준비

배포본(https://andong-itda.vercel.app) 또는 프리뷰. 홈(`/`)에서 시작한다.
**안동 안에서 하면 가장 좋다.** 밖에서 하면 안동역 기준 화면이 되는데, 그것도
실제로 존재하는 상태이니 그대로 진행해도 된다.

## 과제

### 1. "지금 있는 자리에서 하회마을 가는 버스를 찾아보세요."

보는 것
- 검색창을 쓰는가, 상단 "둘러보기"로 가는가
- "목적지"라는 말이 통하는가 — 칩이 떴을 때 그게 무슨 뜻인지 아는가
- 승강장 칩이 다시 서는 것을 알아채는가

### 2. "그 버스를 타면 몇 분쯤 걸리는지 말해보세요."

보는 것
- `○○까지 약 44분`을 찾는가
- 아래 내역(`36정거장 전 · 기다리기 32분 · …`)을 읽는가, 지나치는가
- **`36정거장 전`을 무엇으로 읽는가** — 버스의 현재 위치로 읽으면 성공,
  "목적지까지 36정거장"으로 읽으면 이 줄의 자리를 다시 봐야 한다

### 3. "하회마을에서 돌아오는 막차가 몇 시인지 확인해보세요."

보는 것
- 돌아오는 편 블록을 찾는가
- **"시간표가 공식 자료에 없어요"를 이해하는가** — "앱이 고장났다"로 읽는지
  "원래 없는 정보"로 읽는지. 이 서비스에서 가장 중요한 문장 중 하나다(→ ADR-016)
- 포기하는가, 상세 화면까지 들어가는가

### 4. "안동역으로 가는 버스로 바꿔보세요."

보는 것
- "지우기"를 찾는가
- 지운 뒤 검색창이 돌아오는 것을 알아채는가
- "안동역"을 검색해 **정류장** 결과를 고를 수 있는가 (관광지가 아니다)

## 끝나고 묻는 것 (딱 셋)

1. 이 화면에서 **가장 먼저 눈에 들어온 것**이 무엇이었나요?
2. **필요 없다고 느낀 것**이 있었나요?
3. 이 화면에 **없어서 아쉬웠던 것**이 있었나요?

## 이 테스트로 답하려는 것

| 의심 | 어느 과제가 답하나 |
|---|---|
| 목적지 검색을 발견하는가 | 1 |
| 총 소요시간이 읽히는가 · 내역이 필요한가 | 2 |
| `36정거장 전`의 자리가 맞는가 | 2 |
| 돌아오는 편이 44곳 중 2곳만 시각을 말하는데 그래도 값이 있는가 | 3 |
| 목적지 교체 동선(지우기 → 재검색)이 통하는가 | 4 |
| 정류장이 목적지가 된다는 것을 아는가 | 4 |

⚠️ **고칠 것은 테스트 뒤에 정한다.** 테스트 전에 고치면 무엇 때문에 나아졌는지
알 수 없다. 화면 합치기(→ ADR-051)는 이 테스트와 별개로 이미 끝냈고, 이 테스트는
**합친 화면**을 대상으로 한다.
