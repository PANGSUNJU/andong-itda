# 공공데이터포털 운영계정 전환 신청 — 활용사례 자료

2026-09-11 배포본(https://andong-itda.vercel.app)에서 직접 캡처했다.
모두 **실제 API 응답이 화면에 그려진 상태**다. 목업이 아니다.

## 서비스 개요 (신청서에 붙여 쓸 문장)

> **안동잇다** — 차 없이 안동을 여행하는 사람을 위한 안내
> https://andong-itda.vercel.app
>
> 한국관광공사 TourAPI와 안동시 버스정보를 한 화면에서 잇는다. 기존에는 관광
> 정보(안동관광)와 교통 정보(안동버스정보)가 따로 있어 여행자가 두 서비스를
> 오가야 했다. 이 서비스는 "이 관광지에 몇 번 버스를 타면 가는가", "버스를
> 기다리는 동안 다녀올 수 있는 곳이 어디인가"에 한 화면에서 답한다.
> 국문·영문 두 언어로 제공하며 회원가입·로그인·개인정보 수집이 없다.
> 2026 한국관광공사 관광데이터 활용 공모전 출품작이다.

## 신청 건별 캡처 대응

| 활용신청 | 캡처 | 화면에서 확인되는 것 |
|---|---|---|
| **국문 관광정보 서비스_GW**<br>(KorService2) | `02`, `03`, `07` | 관광지 44곳의 사진·분류·주소(`areaBasedList2`), 운영시간·휴무일·주차·문의(`detailIntro2`), 축제 기간·장소(`searchFestival2`) |
| **기초지자체 중심 관광지 정보**<br>(LocgoHubTarService1) | `01`, `02` | "안동에서 많이 찾는 곳" 방문 기반 순위, 목록의 인기순 정렬과 순위 배지 |
| **영문 관광정보서비스_GW**<br>(EngService2) | `05` | 영문 관광지명(Andong Hahoe Village), 영문 이용 안내(`detailIntro2`) |
| **관광지별 연관 관광지 정보**<br>(TarRlteTarService1) | `04` | "함께 많이 찾는 곳" — 거리가 아니라 방문 행동으로 고른 목록 |
| **관광사진 정보_GW**<br>(PhotoGalleryService1) | `06` | 부용대 대표 사진. 국문 관광정보에 사진이 없던 곳을 이 API가 채웠다 |

`08`은 모든 신청 건에 공통으로 쓴다 — 서비스 안에 상시 노출되는 **출처 표기 화면**이다.

## 활용 현황 (숫자로 적어야 할 때)

```
관광지        44곳   (기초지자체 중심 관광지 + 국문 관광정보 병합)
음식점        28곳   (국문 관광정보, 법정동 코드 조회)
이용 안내     국문 34곳 · 영문 13곳
연관 관광지   21곳
영문명        17곳
축제          열리거나 30일 내 시작하는 것만 노출
사진          35/44곳 (국문 관광정보 → 관광사진 정보 순으로 보충)
```

⚠️ 원천 데이터를 파일로 내려받아 쓰지 않는다. 전부 OpenAPI 호출이고, 응답은
서버에서 캐시(관광 정보 1일 · 버스 1분)한다. 공모전 심사 요건과 같은 기준이다.
